# Clases-hijas-en-java
Ejercicio sencillo en Java con Netbeans para mi universidad, son 3 ejercicios en uno. El primero es un proyecto con clases dentro para aplicar fórmulas matemáticas sencillas como perímetro y área de 3-4 figuras geometricas, el segundo es una cuenta bancaria, con una cuenta dentro y la substracción de efectivo y que salga saldo insuficiente, etc.
